# Sample website directories

These files are realistic version-1 YamiNet directory documents used by the
`yami-discover` demo, CLI examples and tests.

- `community.ylang` — a general community listing.
- `garden.ylang` — an independently edited "indie web" listing.
- `lab.ylang` — a technical/lab index.

The `yn1-` identities are **synthetic**. The sites do not exist and nothing
here is a live service or a trust recommendation. The documents are ordinary
YLang 0.2 files and can be read with the existing YLang tooling.

Two entries are deliberately listed by more than one source:

- "Alice's Notebook" (community) and "Alice's Field Notes" (garden) use the
  same canonical address.
- "The Quiet Corner" (community) and "The Quiet Corner" (lab) use the same
  canonical address.

The first imported source wins; the later copies demonstrate duplicate
reporting. See [website discovery](../../docs/discover.md) and the
[format specification](../../docs/specs/v0.4/website-directory.md).
